# Be Vietnam Pro

Nguồn: gói npm chính thức `@fontsource/be-vietnam-pro@5.3.0`, tải bằng npm pack với kiểm tra integrity của npm. Font được phân phối theo SIL Open Font License 1.1; nguyên văn trong fontLicense.txt.

Giữ nguyên bytes WOFF2, chỉ đổi tên tệp theo lowerCamelCase. Bao gồm subset vietnamese/latin-ext/latin, trọng lượng 400/500/600/700, normal. Các Unicode ranges trong typography.scss lấy từ CSS của gói. Không có yêu cầu tải font từ mạng khi chạy.
