Thả video hoặc nối cổng Video đầu vào, chỉnh **Prompt phân tích** và chọn mô hình. Bấm **Gửi video để phân tích** để gửi video và prompt trong cùng một yêu cầu. Nhập thông tin sản phẩm mới nếu muốn áp dụng cấu trúc video mẫu cho sản phẩm khác.

Chế độ Video cần mô hình nhận tệp video. Với tệp lớn, node dùng FFmpeg để tạo bản MP4 nhỏ hơn, giữ thời lượng và âm thanh nguồn. Bạn có thể cài FFmpeg trong Chợ plugin.

Chế độ Khung hình gửi ảnh mẫu kèm prompt tới mô hình đọc ảnh. Kịch bản API trả về hiển thị ngay trong node để chỉnh sửa, sao chép hoặc chuyển sang node khác qua cổng văn bản.
