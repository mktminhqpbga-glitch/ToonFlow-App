Thả video hoặc nối cổng Video đầu vào, chọn một mô hình trong Cài đặt rồi bấm Phân tích video. Nhập sản phẩm mới để viết lại kịch bản theo cấu trúc của video tham chiếu.

Chế độ Video cần mô hình nhận tệp video. Với tệp lớn, node dùng FFmpeg để tạo bản MP4 nhỏ hơn, giữ thời lượng và âm thanh nguồn. Bạn có thể cài FFmpeg trong Chợ plugin.

Chế độ Khung hình gửi ảnh mẫu và tạo lời thoại đề xuất. Kết quả là kịch bản tiếng Việt, có thể chỉnh sửa, sao chép hoặc chuyển qua cổng văn bản sang node khác.
